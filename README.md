# Pavel Pastore — DarkxElocius

I'm a developer working mostly in PHP (Symfony/Laravel), with regular detours into C# and TypeScript. Most of what I ship these days goes out under **DummyThinking**, the studio I run.

## What I'm building

- **Page Forge** — a developer-targeted CMS built on Laravel, for rapid client website deployment
- **Atlas UI** — a React component library
- **Vex** — a statically-typed, object-oriented language that compiles to bytecode and runs on a stack-based VM
- **Evie-AI** — a persistent, always-on AI voice companion with memory and a web dashboard
- **Vellichor** *(working title)* — a text-based RPG currently in development
- A handful of smaller tools: a self-hosted personal media library, a Markdown-to-single-file-HTML converter, and a DayZ server economy editor

## Background

DummyThinking started years ago as a small Minecraft modding team, founded by [Modbder](https://github.com/Modbder), who taught me the basics of programming and Java. My first released mod picked up a solid number of downloads, and a few features from it later showed up in other people's mods.

The original team is long gone, and I'm the only one left from that era — though I'd love to get back to modding again someday. DummyThinking also covers my web projects these days, currently built together with one other collaborator who joined later and isn't involved on the gaming side. Once we land on a company name, those bigger projects will move out to a new org of their own, and DummyThinking will go back to being the gaming/modding side of things.
